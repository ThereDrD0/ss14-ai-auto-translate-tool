# Автоматический перевод в GitHub Actions

## Запуск по расписанию в GitHub

В [examples/github-actions/auto-translate.yml](examples/github-actions/auto-translate.yml) лежит готовый шаблон. Скопируйте его в `.github/workflows/auto-translate.yml` основного репозитория игры. Если сабмодуль расположен иначе, измените `TOOL_PATH`.

В настройках основного репозитория GitHub откройте `Settings → Secrets and variables → Actions` («Настройки → Секреты и переменные → Actions»):

- В переменные добавьте `TRANSLATE_AI_BASE_URL`, `TRANSLATE_AI_MODEL` и реальный `TRANSLATE_AI_MAX_OUTPUT_TOKENS`.
- В секреты добавьте `TRANSLATE_AI_KEYS`.
- В `Settings → Actions → General → Workflow permissions` разрешите Actions создавать запросы на слияние.

Шаблон запускается ежедневно в 03:17 UTC и вручную через `workflow_dispatch`. При ручном запуске по умолчанию включён пробный режим. Без API-настроек автоматический перевод пропускается. GitHub-исполнителю нужен доступный извне API: адрес `127.0.0.1` вашего домашнего компьютера ему недоступен.

После настоящего запуска создаётся или обновляется черновой запрос на слияние только с изменениями `Resources/Locale`. При частичном сбое проверенные результаты сохраняются, отчёт прикладывается к запуску. Автоматического слияния нет.

Каждый запуск шаблона начинается с основной ветки игры. Пока предыдущий запрос не слит, сохранённые в нём переводы ещё не входят в основную ветку и могут переводиться повторно. Для продолжения именно с этих результатов запустите инструмент на ветке запроса или сначала слейте проверенные изменения.

Если нужно, чтобы созданный запрос запускал остальные проверки репозитория, задайте секрет `LOCALIZATION_GITHUB_TOKEN` с правами записи содержимого и запросов на слияние. Стандартный `GITHUB_TOKEN` может не запускать новые события автоматизации.

Подробности разрешений и поведения токенов: [документация create-pull-request](https://github.com/peter-evans/create-pull-request).

Сам `ci.py` не выполняет операции Git: сохранение ветки и создание запроса на слияние поручены шаблону GitHub Actions. Установка шаблона ещё не означает его запуск.
Другие настройки из [CONFIGURATION.md](CONFIGURATION.md) при необходимости добавьте в раздел `env` сценария. Шаблон не получает все переменные репозитория автоматически.
