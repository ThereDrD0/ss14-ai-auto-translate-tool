# Как добавить словарь для нового языка

Скопируйте этот файл рядом с собой и назовите `<код-языка>-GLOSSARY.md`, например `fr-FR-GLOSSARY.md`. Код должен совпадать с кодом целевого языка, который вы выбираете в программе. Файл `.example.md` программа не использует.

Запишите пары «исходный термин → желаемый перевод». Добавляйте только слова, для которых нужен определённый перевод в игре. Одну пару пишите на одной строке:

- toolbox → пример перевода на ваш язык

Удалите эту инструкцию и пример перед использованием. Если особых терминов нет, файл создавать не нужно.
