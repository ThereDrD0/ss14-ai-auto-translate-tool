# Подробные настройки

## Pass-лист: названия, которые не переводятся

`pass_list.yml` содержит список `ignore_list`. Это названия оружия, марки, сокращения и другие разрешённые слова. Начальный список взят из `Tools/_sunrise/Schemas/ignore_list.yml`, который использует проверка локализации игры. Если этот файл есть в основном репозитории, его слова автоматически добавляются к встроенным.

Разрешённая фраза исключается из языкового подсчёта, но не вся строка с ней. Например, `Desert Eagle` разрешено, а английское описание рядом с ним всё равно требует перевода. Во время перевода название сохраняется дословно, включая регистр.

При поиске разрешённых слов регистр не учитывается, но модель обязана сохранить тот регистр, который был в исходном тексте. Технические сокращения прежнего переводчика также сохранены в начальном списке.

Свой YAML-файл задайте через `TRANSLATE_PASS_LIST` или `--pass-list`. Он заменяет встроенный список:

```yaml
ignore_list:
  - Desert Eagle
  - M1 Garand
```

Исключения целых файлов из старой проверки по умолчанию не применяются. Если это намеренно нужно, добавьте `ignore_files` в свой список и задайте `TRANSLATE_PASS_IGNORE_FILES=true`. Синтаксис таких файлов всё равно проверяется.

## Проверка языка

По умолчанию требуется не менее 80% целевого языка в каждом видимом поле после исключения pass-листа и разметки. Порог задаётся `TRANSLATE_LANGUAGE_RATIO=0.8` или `--language-ratio 0.8`.

Встроенный определитель [Lingua](https://github.com/pemistahl/lingua-py) поддерживает 75 языков, а не только русский и английский. Это статистическая оценка: короткие слова и близкие языки могут распознаваться неверно. Синтаксис FTL и совпадение ключей проверяются независимо от определения языка.

Для другого языка можно подключить собственный словарный профиль через `TRANSLATE_LANGUAGE_PROFILE` или `--language-profile`. Пример для языка с кодом `tlh`:

```yaml
language: tlh
words:
  - Qapla
  - nuqneh
```

В профиле нужен достаточно полный словарь целевого языка: доля распознанных букв слов должна достигать заданного порога. Неподдерживаемый язык без профиля вызывает явную ошибку, а не ложное сообщение об успешном переводе.

## Размер блоков и параллельная обработка

Размер окна модели пользователь задаёт вручную в `TRANSLATE_AI_MAX_OUTPUT_TOKENS`. Он не определяется по названию модели.

Если используется несколько моделей или сервисов, укажите наименьшее доступное окно среди них.

Токены — единицы текста, которыми сервис измеряет объём ответа. По умолчанию используется консервативная оценка по UTF-8-байтам, тройной запас на расширение перевода и только 65% выходного окна:

```dotenv
TRANSLATE_AI_MAX_OUTPUT_TOKENS=8192
TRANSLATE_AI_TOKENIZER=bytes
TRANSLATE_AI_OUTPUT_EXPANSION=3
TRANSLATE_AI_OUTPUT_SAFETY=0.65
TRANSLATE_AI_OUTPUT_RESERVE=128
```

Если точно известна кодировка токенизатора модели, вместо `bytes` можно вручную выбрать `cl100k_base` или `o200k_base`. Запас всё равно применяется. Для дополнительного ограничения входного окна задайте `TRANSLATE_AI_MAX_INPUT_TOKENS`; в него учитываются подсказка, словарь, pass-лист и обратная связь.

Некоторые API называют параметр окна ответа `max_completion_tokens`, другие — `max_tokens`. Выберите нужное имя через `TRANSLATE_AI_TOKEN_LIMIT_FIELD`. В первом варианте рассуждения модели тоже могут расходовать окно; ориентируйтесь на документацию своего сервиса.

Большие сообщения разделяются внутри текстовых значений. Если даже неделимый элемент не помещается, инструмент сообщает об ошибке и не отправляет заведомо слишком большой блок. При обрезанном ответе он уменьшает блок. Гарантировать длину произвольного ответа ИИ математически нельзя, особенно если сервис включает рассуждения модели в то же окно; повреждённый результат не сохраняется.

`TRANSLATE_CONCURRENCY` или `--concurrency` задаёт число одновременно переводимых файлов. `TRANSLATE_BATCH_SIZE` ограничивает группу файлов одного прохода. `TRANSLATE_CHUNK_SIZE` — дополнительный предел исходных символов, но он не отменяет более строгий бюджет ответа.

## Ошибки и продолжение

Временные сетевые ошибки и ограничения частоты запросов повторяются. После ограничения частоты действует `TRANSLATE_AI_COOLDOWN_SECONDS` (по умолчанию 60 секунд). Ошибка авторизации требует исправления ключа.

`TRANSLATE_AI_MAX_ATTEMPTS=0` означает неограниченные сетевые повторы; положительное число ограничивает их. Повторы плохих ответов ограничены `TRANSLATE_AI_RESPONSE_MAX_ATTEMPTS` (по умолчанию 3).

Параметр `--allow-partial` сохраняет успешно проверенные блоки даже при ошибке другого блока. Повторный запуск продолжает непереведённые части. При оставшихся ошибках процесс возвращает ненулевой код завершения. `--report-json` сохраняет машинный отчёт; JSON используется только для отчёта, не для обмена переводимым текстом с ИИ.
