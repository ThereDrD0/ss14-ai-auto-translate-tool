# Цветовая палитра интерфейса

Используйте эти цвета для терминального интерфейса. Новые элементы должны повторять роль существующих: кнопка выглядит как кнопка, панель — как панель. Если действительно нужен новый цвет, добавьте его сюда и обновите проверку палитры.

| Роль | Цвет | Где применяется |
| --- | --- | --- |
| screen | `#111821` | фон экрана и поля ввода |
| panel | `#18232e` | панели, списки, диалог |
| header | `#1c2b39` | верхняя и нижняя полосы |
| button | `#243746` | обычная кнопка |
| selected | `#355467` | наведение, фокус, выбранный пункт |
| border | `#506474` | обычная рамка |
| focus | `#83b4c7` | рамка в фокусе |
| text | `#d4dde7` | основной текст |
| white | `#ffffff` | текст выбранного элемента |
| muted | `#a9b9c6` | второстепенный текст |
| hint | `#c3d1da` | нижняя строка подсказок |
| header_text | `#e6edf4` | текст заголовка |
| title | `#a9c7d9` | заголовки и подписи таблиц |
| success | `#a8cfb1` | готовые действия и стрелка сравнения |
| error | `#e2a2a5` | ошибка |
| retry | `#d5bd94` | повтор запроса |
| active | `#aac6d5` | начатая работа |
| removed | `#cbbba5` | удалённый файл |
| neutral | `#c2d0dc` | прочие строки журнала |
| selected_log | `#314657` | выделенная строка журнала |
| diff_removed | `#a97979` | удалённый текст сравнения |
| diff_added | `#9bd3a9` | добавленный текст сравнения |
| diff_context | `#8799a6` | номера и неизменённый текст сравнения |
| diff_removed_bg | `#613434` | фон удалённого текста |
| diff_added_bg | `#285b3c` | фон добавленного текста |
| overlay | `#000000` | затемнение за модальным окном, только с прозрачностью |
