# Автоматический ИИ перевод локализации Space Station 14

Инструмент предоставляет TUI приложение для автоматического перевода Space Station 14 с любой существующей локали на любую другую локаль с помощью ИИ по API

Реализованные фичи:
- Удобный TUI интерфейс с подсказками
- Автоматическое форматирование перед началом перевода
    - Размещает строки ровно в том порядке, какой используется в исходном языке
    - Автоматическое создание локалей из прототипов
    - Авто-форматирование FTL: правильные отступы, пробелы 
- Перевод с любого языка существующего языка на 70+ доступных
- По максимуму экономит токены ИИ, стараясь минимизировать количество запросов для доступного окна ответа
- Автоматические проверки ответа ИИ с ретраями. 
    - При ошибке ИИ получает информацию об своей прошлой ошибке с инструкцией к исправлению
- Специализированные инструкции для повышения качества
    - Словарь терминов для более качественного перевода специфичных слов
    - Pass-лист слов, которые модель не должна переводить, отдельно для каждого целевого языка
- Режим проверки изменений с возможность отправить файл на реперевод в 1 клик
    - Доступна возможность указать пожелания для реперевода в всплывающем окне.

## Quick start

- [Git](https://git-scm.com/downloads)
- [Python 3.10 или новее](https://www.python.org/downloads/) с `pip` — установщиком библиотек. 
    - На Windows включите `Add Python to PATH` («добавить Python в системный путь»).

Следующие команды запускать из корня репозитория игры

**Скачивание и подключение сабмодуля**
```text
git submodule add https://github.com/ThereDrD0/ss14-ai-auto-translate-tool Tools/ss14-ai-auto-translate-tool
git submodule update --init --recursive
cd Tools/ss14-ai-auto-translate-tool
```

**Запуск**
```python
python run.py
```

### Обновление

Обновиться до версии, уже загруженной в гит
```
git submodule update --init --recursive
```

Обновить версию до новой версии из оригинального репозитория
```
git submodule update --remote -- Tools/ss14-ai-auto-translate-tool
```

### Известные баги

1. Цвета в формате HEX считаются непереведенными строками
2. Логи не показывают конкретное название ошибки, пока их не развернешь
3. Ctrl+Enter не работает(как минимум в Windows терминале)
4. Множество легитимных строк может считаться за непереведенные из-за намеренно оставленных английских слов
