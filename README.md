# Автоматический перевод локализации Space Station 14

Этот инструмент переводит стандартную локализацию Space Station 14 при помощи ИИ. Он сравнивает исходную и целевую папки Fluent (`.ftl`), восстанавливает зеркальные пути и порядок ключей, сохраняет существующие переводы и добавляет недостающие сообщения.

ИИ получает обычный FTL-текст без JSON-обёртки. Ответ проверяется настоящим парсером Fluent, проверками структуры и доли целевого языка. Названия из [pass-листа](pass_list.yml) не переводятся и не мешают проверке языка. Несколько файлов могут обрабатываться асинхронно.

Инструмент рассчитан на установку внутрь репозитория игры как сабмодуль Git. Корень игры определяется автоматически по папке `Resources/Locale`, поэтому конкретное место установки не зашито в коде.

## Установка

Из корня репозитория Space Station 14 выполните:

```text
git submodule add <АДРЕС_РЕПОЗИТОРИЯ_ИНСТРУМЕНТА> Tools/ss14-ai-auto-translate-tool
git submodule update --init --recursive
```

Вместо `<АДРЕС_РЕПОЗИТОРИЯ_ИНСТРУМЕНТА>` укажите адрес после публикации этого проекта.

Отдельное виртуальное окружение не требуется: зависимости автоматически устанавливаются в локальную папку `.deps`. Настройка Python, подключения к ИИ и команды запуска для Windows и Linux описаны в [HOW_TO_SETUP.md](HOW_TO_SETUP.md).

Языки, подсказки, словарь и окно ответа модели задаются через `.env` и параметры запуска. Для английского и русского есть отдельные подсказки; для других языков — универсальная и возможность добавить собственную. Встроенный определитель знает 75 языков; для остальных предусмотрен пользовательский словарный профиль.

Интерактивный запуск после настройки:

```text
python run.py
```

На первом экране стрелками ↑/↓ выбираются исходная и целевая локали; Tab или ←/→ переключают колонки. Enter открывает список моделей, полученный от настроенного сервера через `/v1/models`, и запускает перевод. Во время работы видны прогресс, примерное оставшееся время, активные файлы и журнал с полным текстом переводов. После завершения остаётся экран итогов. Число токенов показывается, если сервер возвращает поле `usage`. Выход — Ctrl+C. Если инструмент запущен вне папки игры, укажите `SS14_REPO_ROOT` с путём к репозиторию игры.

Быстрый запуск через скрипты после настройки:

```text
# Windows
.\scripts\windows\translate-all-ru.cmd

# Linux
bash ./scripts/linux/translate-all-ru.sh
```

Пробный запуск: добавьте `-DryRun` на Windows или `--dry-run` на Linux. Он не отправляет запросы к ИИ и не записывает переводы.

Готовый [шаблон GitHub Actions](examples/github-actions/auto-translate.yml) запускает перевод по расписанию и создаёт черновой запрос на слияние в основном репозитории игры. Его нужно установить отдельно по инструкции; сам инструмент не делает коммиты и не отправляет изменения.
